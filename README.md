# 安装命令
```
regsvr32 gpuselect.dll
```

# 卸载命令
```
regsvr32 /u gpuselect.dll
```

# 如何调试
DLL被explorer占用的时候会无法调试。按照以下操作：
方法1：
    1. 使用 regsvr32 /u 解除gpuselect.dll文件的注册
    2. 打开任务管理器备用
    3. 按住 ctrl + shift 在任务栏点右键，会出现“退出资源管理器”，点击它
    4. 在任务管理器的“进程”页面，点击“运行新任务”，输入 explorer 重新运行
方法2：
    1. 打开任务管理器
    2. 在“进程”页面找到“资源管理器”，右键点击它，选择“重新启动”
    有的时候这个方法会无效，暂时还没找到规律。上面那个总是可以用。
